# Job Market Skill Analyzer

Assignment 01 - Python Data Structures (Advanced Data Science Program).

## Files
| File | Purpose |
|---|---|
| `Job_Market_Skill_Analyzer.ipynb` | Notebook with complete code and outputs |
| `main.py` | Same code as a script |
| `job_skills.csv` | Generated: cleaned job records |
| `top_skills.txt` | Generated: top skills and counts |

## Setup (virtual environment)
```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # macOS/Linux
pip install -r requirements.txt
```
In VS Code select the `venv` interpreter / notebook kernel.

## Run
```bash
python main.py
```
The program asks how many postings to add, then role, company and skills for each.
